# agentic-research-playbook

A reusable operating framework for running an agentic system across hundreds of independent, adversarially-graded knowledge-work targets — orchestration, production/verification separation, compounding institutional memory, and grading-function-aware strategy.

Distilled from winning the Hugging Face *ICML 2026 Agent Reproducibility* hackathon (363 papers reproduced, 1st of several hundred entrants). See **[PLAYBOOK.md](PLAYBOOK.md)** for the full framework.

This repo is the reusable distillation, not the source project — it deliberately excludes competition-specific tooling and identifiers so the lessons transfer to unrelated future work.
